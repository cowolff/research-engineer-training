{# One reply arriving token by token (§5.7). `stream.js` opens an EventSource on `data-stream-url` and appends each delta as a *text node* — never as HTML. What is on screen here is raw, unsanitised model output, so it is shown as literal text and nothing else; the markdown-rendered, nh3-sanitised version arrives with the htmx swap below, which fires once on the `stream-done` event the same script dispatches. That split is deliberate: the animation never gets to inject anything, and the final content never has to be trusted to a client-side renderer.
